# 取色和清洗加速

相同初始姿态，相同序列：颜色 0、7、16、23，每次取色后清洗。均包含移位、浸入、停留和抬笔。基准版本为 Git `431a537`。

|动作|之前均值|现在均值|时间减少|
|---|---:|---:|---:|
|取色|13.63 s|4.65 s|65.9%|
|清洗|13.93 s|5.09 s|63.5%|

降低不必要的移动高度，去掉重复对齐和固定空等；使用限速、限加速度的五次曲线与自由空间速度前馈。取色和清洗仍实际浸入，各自停留 0.10 s、0.30 s。停留时长是仿真工程选择，不代表真实清洗效能。绘画力控与物理时间步保持原配置。

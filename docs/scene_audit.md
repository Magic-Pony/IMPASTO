# 场景与工具装配核对（正文 III-C、图 3、附录 A、图 A1）

结论：旧版本的长笔和工位布局不合理。本轮补齐装配链，缩短画笔，将调色盘与清洗器移到画布两侧；模型的功能组成已对齐论文，但不能称为全部硬件、材料和控制器的精确复现。

## 布局、接近路径与验收

世界 XY（单位 m）：画布 `(0.50, 0.00)`，调色盘 `(0.43, -0.37)`，水盆 `(0.43, +0.37)`。桌面范围 `x∈[0.14,0.96]`、`y∈[-0.55,0.55]`。调色盘、水盆及画布均完整位于桌面内，容器与画布之间有间隙。

图 3 给出画布两侧的布局关系，没有给绝对位置、朝向和桌高；本地布局是根据可达性设计的，不宣称是原论文坐标。相机视角不同也会改变画面中的“左右”。

每次蘸洗依次进行：原位置竖直抬高 → 保持笔轴向下移至目标上方 → 竖直下降 → 检查 XY 偏差、浸入深度、倾角 → 抬笔。移位使用零速度起停的三次时间曲线，洗笔时旋转器转动、画笔保持不动。蘸漆目标浸深 5 mm，清洗目标浸深 15 mm。目标直接读取场景几何，避免移动容器却仍去旧坐标。

`bash scripts/run.sh scripts/audit_scene.py` 实际执行 24 次蘸漆和 24 次清洗，检查整段路径倾角、超过 0.5 mm 的意外几何穿透，另测试所有工位的竖直 IK 和画布内部 5×5 网格。网格是离散可达性检查，不构成整块画布所有连续轨迹的证明。

## 力值与复现边界

旧版本把接触力乘 `0.08` 的做法已经移除。当前 `normal_force()` 等于 MuJoCo 原始刷尖/画布接触法向力（N）；六维安装点传感器单独由 `tool_wrench()` 返回，含工具重量与惯性载荷。报告只将前者称为接触力，不混称为昆维传感器实测力。

默认物理步长 2 ms、控制周期 4 ms；关节附加伺服增益 2400/26，含重力补偿。落笔以滤波力误差调高度，达到目标 ±0.04 N 并持续 0.16 s 后运笔，运笔仍持续进行高度反馈。这是本地仿真选择；论文的显式前馈力矩注入、仅保持高度的运笔阶段尚未严格实现。现有测试集中于约 0.5–0.65 N 演示工况，不声称验证了论文整个 0.1–4 N 范围。

# 阶段三当前版本变更说明

本文件记录阶段三实现与实验的改动边界。公开的最终版本是只修复诊断错误的 1107014 corrected baseline；后续通用规划优化保留为历史记录，没有进入最终配置。项目没有实现论文中的对比 baseline，也没有把本地仿真结果表述为真实机器人或真实油画物理结果。

## 更加对齐论文的实现

- 使用阶段二训练的 IMPASTO-UNet 作为 learned dynamics model，并在规划时进行多步 rollout。
- 实现 PCA–RANSAC 笔画初始化、加权 L1 终端图像目标、MPPI 的 elite softmax 序列更新，以及按时间步维护协方差和步长的 CMA 风格自适应。
- 多笔任务采用论文给出的 `H=5`；每轮执行两笔，然后读取仿真画布并重新规划。
- Flower 和 Fish 保留论文描述的 17/18 笔规模。
- 使用作者公开 Fig. 8 的 2、5、7、10、12、15 笔和最终状态作为公开检查点，避免伪造论文没有发布的逐笔动作标签。
- 保留阶段二的 900 个 self-play 训练样本、100 个验证样本，以及论文给出的网络、优化器和训练流程设置。

## 为修正本地实现而做的修改

- 修正公开 prefix 目标的角色：公开的 2/5/7/10/12/15 笔图像仅作为审计检查点和阶段目标，正式 refined 规划不再把它们当作逐笔真值或 prefix oracle。
- 统一 learned dynamics 预测和 MuJoCo 执行使用的有效透明度；正式配置使用 `opacity_scale=1.0` 的不透明任务颜料分支，移除历史版本中把照片透明度比直接乘到沉积率上的后验缩放。
- 对候选动作施加工作空间、画布边界和完整 Bézier 轨迹约束，避免只检查笔画起点而让中间轨迹越界。
- 历史实验曾增加颜色引导 proposal 分解；该通用优化没有进入最终 corrected baseline。
- 调整阶段一、阶段二的画笔宽度/沉积参数和数据采样，使训练数据覆盖短笔画、重叠笔画和阶段三使用的颜色与力范围；这些变化服务于本地 learned model 的可用性。

## 论文没有完全说明、但本地必须补齐的部分

- 论文没有公开候选数、MPC 迭代次数、softmax 温度、RANSAC 阈值和 CMA 系数；当前 refined 值集中在 `configs/stage3_baseline_1107014_final.json`，并在报告中标注为本地选择。
- 论文没有发布 Flower/Fish 的原始高分辨率目标图和逐笔动作标签；当前目标来自公开 Fig. 8 的 panel crop，动作由本地规划器推断。
- 论文使用的 25×25 实测颜料 patch 数据库没有公开；最终版本使用由本地仿真采集的 patch 均值/协方差与 Mahalanobis 分类，并限制到阶段二采样过的颜色集合。
- 论文没有给出照片透明度与本地画布沉积率之间的标定关系；当前采用统一的不透明任务颜料分支作为可重复的本地仿真选择，而不是声称恢复真实照片透明度。
- 本地工具尺寸、画笔夹具细节、目标 panel 裁剪、图像配准和仿真渲染分辨率均依据论文图示和可审计的工程假设补齐，具体值见 `docs/fidelity.md`、`docs/scene_audit.md` 和 `configs/`。

## 当前结果边界

阶段三报告中的执行误差、预测误差、力控误差和轨迹误差都是本地 MuJoCo 简化颜料模型上的结果。LPIPS 因预训练权重校验失败没有计算；不会用随机权重生成该指标。完整结果和视频见 `reports/final_reproduction/report.md` 与 `reports/baseline_1107014_corrected_final/showcase/`。

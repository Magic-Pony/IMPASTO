# 四阶段复现计划

## 1. 建立仿真环境
1. Panda 七自由度机械臂、六维力传感器代理、垂直圆头笔刷、18×21 英寸画布、24 槽调色盘、清洗器、俯视相机。
2. 执行六维动作 `(x0,y0,length,bend,angle,force)`；颜色 RGBA 单独指定。
3. 起笔阶段滤波法向力误差并积累前馈作用力，达到目标力后保持高度以阻抗模式完成曲线；平面内轨迹为论文式二次 Bézier。
4. 实际运动、接触力和笔刷载漆状态驱动画布更新。无接触、无颜料不能画出笔画。
5. 完整换色、清洗、蘸漆、移动、落笔、运笔、抬笔、观测流程。
6. 无实时等待、按需相机渲染、独立多进程并行环境；固定任务和种子验证可重复性。
7. 验收：场景图、完整流程视频、接触力和轨迹数据、力-宽度校准、步长敏感性、并行性能和独立性。阈值为本项目工程验收值，非论文公布值。

## 2. 前向动力学模型学习
以正文报告的 900 个训练样本为主要数量对齐点，记录验证数量及划分依据；覆盖单笔和叠画，测试任务不泄漏进训练集。
采用 100×100 灰度局部图像、动作预渲染、6D 动作编码和 U-Net。Adam，lr=5e-4，weight_decay=1e-3，batch=120，1000 epochs，每 100 epoch 学习率×0.75；加权 L1；同步变换动作和图像的数据增强。
验收单步、叠画、五步滚动预测与背景保持。颜色检索使用预混色块与 Mahalanobis 距离。

## 3. 绘画实现
先 H=1 单笔与叠画，再 H=5、每次执行两笔的闭环 MPC；PCA–RANSAC 初始化，精英筛选、MPPI 式更新与 CMA 风格协方差自适应。
Flower/Fish 使用阶段目标图像；复杂画作逐笔跟随作为独立协议。没有作者原始图像时使用明确标注的替代任务。
不复现 FRIDA-CNN、IMPASTO-LR、Heuristics-only baseline。
分别记录模型预测和环境执行的 weighted L1/LPIPS、规划耗时和失败率。

## 4. 代码整理
整理 CLI、配置、数据版本、依赖锁定、报告生成与复现说明。随机种子、日志、版本与数据划分从阶段 1 即开始管理。

## 当前里程碑
- 阶段 1：本地仿真环境已实施并完成力控、场景、画布更新、工位和并行吞吐验收；MuJoCo 接触与颜料沉积仍是论文硬件/真实油画过程的仿真替代。
- 阶段 2：已完成 refined 版本 1000 条转移采集（900 训练、100 episode-held-out 验证）、U-Net 训练 1000 epochs 和独立脚本评估。最佳验证全 patch L1 为 0.008487，变化区域 L1 为 0.028098；数值只作实现参考，因为数据来自本地仿真。
- 阶段 3：已完成单笔和 Flower/Fish 闭环规划、MuJoCo 执行及结果记录。H=5、每轮执行两笔、目标检查点与 17/18 笔数量对齐论文；因作者原始目标素材未发布，Flower/Fish 为明确标注的本地确定性替代目标。LPIPS 因 torchvision AlexNet 权重完整性校验失败未计算。
- 阶段 4：已完成基础代码整理、配置分层、报告入口、视频重放和最终文档；当前报告仍明确记录本地仿真与真实论文系统之间的边界。

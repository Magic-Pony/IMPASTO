# 动作与数据约定

全局画布二维坐标单位为米，右手 x/y；角度用弧度；法向目标力单位 N。图像坐标与世界坐标通过显式映射转换。

动作顺序固定为 `[x0,y0,length,bend,angle,force]`，与颜色 `[R,G,B,A]` 分离；笔画曲线中点偏移为 bend/2。

每个 episode 保存种子、环境配置、动作、颜色索引、每笔前后画布 RGB、接触力、实际和目标笔尖轨迹、执行阶段、状态切换、耗时与成功标记。采集失败必须显式记录，不能静默当成成功样本。

局部 100×100 灰度学习 patch 在阶段 2 从全局图像派生，保存裁剪变换。并行任务按 episode seed 决定样本，不能依赖 worker 调度顺序。
